⭐ SARB Prime Rate & Macro-Sensitive Portfolio Stress Tester

 https://github.com/LavayediaB/sarb-portfolio-stress-tester

  To test how a South African investment portfolio handles interest rate changes and currency swings, I built an interactive risk calculator tailored to the local market. The tool models how shifts in the SARB Repo Rate and the USD/ZAR exchange rate impact a mix of government bonds, local stocks, and cash instruments. It calculates bond sensitivity, measures risk across key market sectors, and uses statistical modeling to estimate potential maximum losses over a 10-day period. Powered by live market data, the dashboard lets users run custom stress tests to see exactly how market shocks affect portfolio value in real time.

⭐ Finding the needle in a haystack: Detecting Anomalies in 40,000+ Medical Aid Claim Records

https://github.com/LavayediaB/Healthcare-Fraud-Detection-Engine

 I built a Python pipeline to find the needle in the haystack within inpatient healthcare data.Using Pandas for data ingestion and Seaborn for visualization, I moved beyond basic reporting into predictive risk profiling. By calculating the Z-score for reimbursements, I was able to mathematically define outliers and identify medical providers with suspicious billing patterns.
